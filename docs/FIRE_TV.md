# Fire TV notes

OZLauncher can be sideloaded on Fire OS devices that meet Android API 26 or newer. Amazon may prevent a third-party application from becoming the permanent HOME activity, and behavior changes between Fire OS updates.

OZLauncher does not request Accessibility Service access and does not attempt to bypass OEM launcher restrictions. If Fire OS does not expose a Home-app selector, launch OZLauncher from the app list or use only a user-approved, reputable button-remapping tool.
